## [0.45.3]

### Improvements

- Lower CPU overhead per running flow, as an opt-in. In a 10-flow test, monitoring overhead per flow dropped about 70%. Requires `USE_FSMV2_BENTHOS_METRICS=true` and a container restart

### Fixes

- The Management Console no longer shows old Historian database figures, such as disk usage and job counts, as current while umh-core cannot read the database
- A historian setting containing `{{`, such as a password, no longer stops the historian status from being reported
- Updated dependencies with known vulnerabilities:
  - OpenSSL (libcrypto3 and libssl3), now 3.5.9-r1 (CVE-2026-88822, CVE-2026-88823, CVE-2026-95691, CVE-2026-95692)

  Update to reduce your attack surface.
