The table below lists the available features of our Community and Enterprise plans. Plans are applied to every user and every instance of a company.

To learn more about how plans work at UMH, see [Billing and Plans](README.md). If you are interested in our Enterprise plan, see [How to get an Enterprise license](README.md#how-to-get-an-enterprise-license).

| -- | -- | -- |
| Host your own Unified Namespace | ✓ | ✓ |
| Management Console Access | ✓ | ✓ |
| 70+ bridge templates | ✓ | ✓ |
| Versioning for Data Models | ✓ | ✓ |
| Users per company | 1 | ∞ |

| Instance audit logs | — | ✓ |
| Single sign-on with your own identity provider | — | [Paid add-on](../authentication/enterprise-sso.md) |
