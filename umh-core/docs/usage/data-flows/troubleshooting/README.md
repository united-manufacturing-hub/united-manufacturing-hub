# Troubleshooting

This section covers bridges and write flows that do not run as expected. Each page starts from the message the Management Console shows, explains what it means, and says what to do.

| Page | Read it when |
|---|---|
| [Bridges Do Not Start](bridges-do-not-start.md) | A bridge shows "Pending Creation" and waits for CPU, memory, disk or the bridge limit |
| [Write Flow Topics Rejected](write-flow-topics-rejected.md) | A deploy fails with "the write flow topics need changes", or a write flow stops after an upgrade |
